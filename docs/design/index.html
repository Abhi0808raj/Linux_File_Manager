Product direction

A dependable foundation for personal workflows.

File Manager is an open-source desktop file manager for Linux, Windows, and macOS. Users can customize appearance and layout, while community plugins add actions, previews, and settings through shared controls.

Confirmed scope

  • Material 3 adapted to a desktop interface.
  • Single pane with tabs by default; optional split view.
  • Contrasting colors, light/dark appearance, comfortable/compact density.
  • Plugin actions, previews, and settings; major view replacement remains outside v0.1.

From design to implementation

Validate browsing, customization, copying with conflicts, and plugin use as complete journeys. Then implement shared Qt controls and a theme adapter before extending the workspace and plugin API.

The complete draft PRD, specification, token export, and delivery process accompany this preview in the same directory.
